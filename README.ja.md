# Serpent

[🇺🇸 English](README.md) · [🇨🇳 简体中文](README.zh-Hans.md) · [🇹🇼 繁體中文](README.zh-Hant.md) · [🇯🇵 日本語](README.ja.md) · [🇰🇷 한국어](README.ko.md) · [🇫🇷 Français](README.fr.md) · [🇩🇪 Deutsch](README.de.md) · [🇪🇸 Español](README.es.md)

Apple Silicon 搭載 Mac 向けの、シンプルなネイティブのスネークゲームです。SwiftUI、AppKit、AVFoundation で作られています。実行時にサードパーティ製のライブラリを必要とせず、ネットワーク通信も行いません。

## 操作方法

| 操作 | キー・入力 |
| --- | --- |
| 移動 | 矢印キー、WASD、または盤面上でドラッグ／スワイプ |
| スタート・一時停止・再開 | スペースキー |
| 新しいゲーム | R または ⌘N |
| 一時停止、または設定／遊び方を閉じる | Esc |
| 設定 | ⌘, |

エサを集めるとヘビが伸びます。通常は壁にぶつかると終了しますが、「画面端を通り抜ける」をオンにすると反対側から現れます。自分の体にぶつかると、常にラウンドが終了します。進行方向から直接 180° 反転する入力は無視されます。有効な方向転換を素早く入力すると、入力順に保存され、移動するたびに一つずつ適用されます。

ほかのアプリに切り替えたとき、ウィンドウを最小化したとき、Mac をスリープさせたときは、自動的に一時停止します。戻ったらスペースキーを押すと再開できます。

## 特徴

- サイズ変更とフルスクリーンに対応したネイティブのデスクトップウィンドウ。Retina／高 DPI ディスプレイでも鮮明に表示されます。
- ライト、ダーク、システムの外観を選択可能。初期設定では Mac の外観に合わせます。
- 60 Hz の滑らかな描画、穏やかに明滅するエサ、アニメーション付きのスコア更新。
- 難易度は 3 段階。それぞれのベストスコアを個別に記録します。

  | 難易度 | 1 回の移動にかかる時間 | エサ 1 個あたりの得点 |
  | --- | --- | --- |
  | かんたん | 160 ms | 10 |
  | ふつう | 105 ms | 20 |
  | むずかしい | 70 ms | 30 |

  難易度の変更は次のゲームから適用されます。

- 「設定 → ゲーム」に、独立した「画面端を通り抜ける」スイッチを用意しています。初期設定はオフです。オンにすると、一方の端を越えたヘビが反対側の端から現れます。変更は次のゲームから適用され、自分の体にぶつかると引き続き終了します。ベストスコアは難易度とモードごとに記録され、従来の通常モードの記録も保持されます。

- スタート、エサの獲得、一時停止、ラウンド終了、ベストスコア更新に合わせて、合成音によるやさしい効果音が鳴ります。効果音はオフにできます。
- ベストスコア、各種設定、選択した言語はローカルに保存されます。
- 8 言語に完全対応。設定画面で国旗を使って選択できます。

  | 言語 | 地域 |
  | --- | --- |
  | 🇺🇸 英語 | アメリカ合衆国 |
  | 🇨🇳 簡体字中国語 | 中国 |
  | 🇹🇼 繁体字中国語 | 台湾 |
  | 🇯🇵 日本語 | 日本 |
  | 🇰🇷 韓国語 | 韓国 |
  | 🇫🇷 フランス語 | フランス |
  | 🇩🇪 ドイツ語 | ドイツ |
  | 🇪🇸 スペイン語 | スペイン |

  初期設定では Mac の優先言語に合わせます。設定画面からいつでも変更できます。

## 開発とパッケージ作成

Xcode Command Line Tools と Swift 5.9 以降が必要です。

```sh
swift test
swift run Serpent
./Scripts/build-app.sh
```

パッケージ作成スクリプトは arm64 のアプリと ZIP アーカイブを作成し、アプリの署名を検証します。ディスクイメージも作成する場合は、`BUILD_DMG=1 ./Scripts/build-app.sh` を実行してください。

ローカルビルドにはアドホック署名が付いていますが、Apple Developer ID による公証は受けていません。別の Mac にダウンロードした際に macOS がアプリの起動をブロックした場合は、システムの案内に従って起動を許可してください。

自動テストでは、ゲームのルール、方向転換のキュー、境界条件、自動一時停止、システム言語との照合、全 8 言語の翻訳の網羅性を検証します。

ソースコードは `Sources/Serpent`、翻訳は `Sources/Serpent/Resources`、アプリアイコンとメタデータは `Support` にあります。
