# Serpent

[🇺🇸 English](README.md) · [🇨🇳 简体中文](README.zh-Hans.md) · [🇹🇼 繁體中文](README.zh-Hant.md) · [🇯🇵 日本語](README.ja.md) · [🇰🇷 한국어](README.ko.md) · [🇫🇷 Français](README.fr.md) · [🇩🇪 Deutsch](README.de.md) · [🇪🇸 Español](README.es.md)

Serpent 是一款面向 Apple Silicon Mac 的原生极简贪吃蛇游戏，使用 SwiftUI、AppKit 和 AVFoundation 开发，无第三方运行时依赖，不发起网络请求。

## 开始使用

打开 `dist/Serpent.app`，或先解压 `dist/Serpent-Apple-Silicon.zip`。你可以将应用拖入“应用程序”文件夹。需要搭载 M 系列芯片的 Mac，系统为 macOS 13 Ventura 或更高版本。

本地构建采用临时签名（ad-hoc），尚未经过 Apple Developer ID 公证。如果在另一台 Mac 下载后，macOS 阻止应用打开，请按照系统提示允许应用运行。

## 操作方式

| 操作 | 按键或手势 |
| --- | --- |
| 移动 | 方向键、WASD，或在游戏区域内拖动／滑动 |
| 开始、暂停或继续 | 空格键 |
| 新游戏 | R 或 ⌘N |
| 暂停或关闭设置／帮助 | Esc |
| 打开设置 | ⌘, |

吃到食物后，蛇身会变长。默认情况下，撞到墙壁会结束本局；开启“穿越边界”后可以从对侧出现。撞到自己的身体始终会结束本局。游戏会忽略直接反向的 180° 转弯；快速输入的有效转向会进入队列，在后续的移动步中依次执行。

切换到其他应用、最小化窗口或让 Mac 进入睡眠时，游戏会自动暂停。返回后按空格键继续。

## 功能

- 原生桌面窗口，支持调整大小、全屏和 Retina／高 DPI 显示。
- 提供浅色、深色和跟随系统三种外观，默认跟随 Mac 的系统外观。
- 以 60 Hz 平滑渲染，食物带有柔和的呼吸动画，分数更新时带有动画效果。
- 三种难度，各自保存最高分：

  | 难度 | 每步移动间隔 | 每个食物得分 |
  | --- | --- | --- |
  | 简单 | 160 ms | 10 |
  | 普通 | 105 ms | 20 |
  | 困难 | 70 ms | 30 |

  难度调整在下一局游戏中生效。

- 在“设置 → 游戏设置”中提供独立的“穿越边界”开关，默认关闭。开启后，蛇越过一侧边界时会从对侧出现；开关调整在下一局生效，撞到自己的身体仍会结束本局。每种难度的普通模式与穿越模式分别记录最高分，原有普通模式纪录保留。

- 可开关的柔和合成音效，用于开始游戏、吃到食物、暂停、结束一局和刷新纪录。
- 最高分、偏好设置和语言选择保存在本地。
- 内置八种完整本地化语言，可在设置中通过国旗标识选择：

  | 语言 | 地区 |
  | --- | --- |
  | 🇺🇸 英语 | 美国 |
  | 🇨🇳 简体中文 | 中国 |
  | 🇹🇼 繁体中文 | 台湾 |
  | 🇯🇵 日语 | 日本 |
  | 🇰🇷 韩语 | 韩国 |
  | 🇫🇷 法语 | 法国 |
  | 🇩🇪 德语 | 德国 |
  | 🇪🇸 西班牙语 | 西班牙 |

  默认语言根据 Mac 的首选语言确定，你可以随时在设置中切换。

## 开发与打包

需要 Xcode 命令行工具，以及 Swift 5.9 或更高版本。

```sh
swift test
swift run Serpent
./Scripts/build-app.sh
```

打包脚本会生成 arm64 应用和 ZIP 压缩包，并验证应用签名。执行 `BUILD_DMG=1 ./Scripts/build-app.sh` 还会生成磁盘映像。

自动化测试覆盖游戏规则、转向队列、边界情况、自动暂停、系统语言匹配，以及八种语言的本地化完整性。

源代码位于 `Sources/Serpent`，翻译资源位于 `Sources/Serpent/Resources`，应用图标和元数据位于 `Support`。
