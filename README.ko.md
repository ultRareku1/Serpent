# Serpent

[🇺🇸 English](README.md) · [🇨🇳 简体中文](README.zh-Hans.md) · [🇹🇼 繁體中文](README.zh-Hant.md) · [🇯🇵 日本語](README.ja.md) · [🇰🇷 한국어](README.ko.md) · [🇫🇷 Français](README.fr.md) · [🇩🇪 Deutsch](README.de.md) · [🇪🇸 Español](README.es.md)

Apple Silicon Mac을 위한 간결한 네이티브 스네이크 게임입니다. SwiftUI, AppKit, AVFoundation으로 제작했으며, 실행 시 타사 라이브러리가 필요하지 않고 네트워크 요청도 보내지 않습니다.

## 시작하기

`dist/Serpent.app`을 열거나 `dist/Serpent-Apple-Silicon.zip`의 압축을 풀어 주세요. 앱을 응용 프로그램 폴더로 드래그해 옮길 수 있습니다. macOS 13 Ventura 이상을 실행하는 M 시리즈 Mac이 필요합니다.

로컬 빌드에는 ad-hoc 서명이 적용되어 있지만, Apple Developer ID를 통한 공증은 받지 않았습니다. 다른 Mac에서 다운로드한 뒤 macOS가 앱 실행을 차단하면, 시스템 안내에 따라 실행을 허용해 주세요.

## 조작 방법

| 동작 | 조작 |
| --- | --- |
| 이동 | 방향키, WASD 또는 게임 보드에서 드래그/스와이프 |
| 시작, 일시 정지 또는 계속 | 스페이스 키 |
| 새 게임 | R 또는 ⌘N |
| 일시 정지 또는 설정/게임 방법 닫기 | Esc |
| 설정 | ⌘, |

먹이를 먹으면 뱀이 길어집니다. 기본적으로 벽에 부딪히면 라운드가 끝나지만, 경계 통과를 켜면 반대편 경계로 나옵니다. 자신의 몸에 부딪히면 항상 라운드가 끝납니다. 진행 방향에서 곧바로 180° 반전하는 입력은 무시됩니다. 유효한 방향 전환을 빠르게 입력하면 순서대로 저장되며, 뱀이 이동할 때마다 하나씩 적용됩니다.

다른 앱으로 전환하거나, 창을 최소화하거나, Mac을 잠자기 상태로 전환하면 게임이 자동으로 일시 정지됩니다. 돌아온 뒤 스페이스 키를 누르면 계속할 수 있습니다.

## 주요 기능

- 크기 조절과 전체 화면을 지원하는 네이티브 데스크톱 창. Retina/고해상도 디스플레이에서도 선명하게 표시됩니다.
- 라이트, 다크, 시스템 모양 옵션. 기본적으로 Mac의 모양 설정을 따릅니다.
- 60 Hz의 부드러운 화면 표시, 은은하게 맥동하는 먹이, 애니메이션이 적용된 점수 갱신.
- 세 가지 난이도별로 최고 점수를 따로 기록합니다.

  | 난이도 | 한 번 이동하는 데 걸리는 시간 | 먹이 하나당 점수 |
  | --- | --- | --- |
  | 쉬움 | 160 ms | 10 |
  | 보통 | 105 ms | 20 |
  | 어려움 | 70 ms | 30 |

  난이도 변경은 다음 게임부터 적용됩니다.

- **설정 → 게임**에 독립적인 **경계 통과** 스위치가 있으며, 기본값은 꺼짐입니다. 켜면 한쪽 경계를 넘어간 뱀이 반대편 경계로 나옵니다. 변경은 다음 게임부터 적용되며, 자신의 몸에 부딪히면 여전히 라운드가 끝납니다. 최고 점수는 난이도와 모드별로 따로 기록하고, 기존 일반 모드 기록은 유지합니다.

- 시작, 먹이 획득, 일시 정지, 라운드 종료, 최고 기록 갱신에 맞춰 부드러운 합성 효과음을 재생합니다. 효과음은 끌 수 있습니다.
- 최고 점수, 환경설정, 선택한 언어를 로컬에 저장합니다.
- 8개 언어로 완전히 현지화되어 있으며, 설정에서 국기로 선택할 수 있습니다.

  | 언어 | 지역 |
  | --- | --- |
  | 🇺🇸 영어 | 미국 |
  | 🇨🇳 중국어 간체 | 중국 |
  | 🇹🇼 중국어 번체 | 대만 |
  | 🇯🇵 일본어 | 일본 |
  | 🇰🇷 한국어 | 대한민국 |
  | 🇫🇷 프랑스어 | 프랑스 |
  | 🇩🇪 독일어 | 독일 |
  | 🇪🇸 스페인어 | 스페인 |

  기본 언어는 Mac의 선호 언어 설정을 따릅니다. 설정에서 언제든지 변경할 수 있습니다.

## 개발 및 패키징

Xcode Command Line Tools와 Swift 5.9 이상이 필요합니다.

```sh
swift test
swift run Serpent
./Scripts/build-app.sh
```

패키징 스크립트는 arm64 앱과 ZIP 파일을 만든 뒤 앱의 서명을 검증합니다. 디스크 이미지도 만들려면 `BUILD_DMG=1 ./Scripts/build-app.sh`를 실행하세요.

자동화된 테스트는 게임 규칙, 방향 전환 큐, 경계 조건, 자동 일시 정지, 시스템 언어 매칭, 8개 언어 전체의 번역 완전성을 검증합니다.

소스 파일은 `Sources/Serpent`, 번역은 `Sources/Serpent/Resources`, 앱 아이콘과 메타데이터는 `Support`에 있습니다.
