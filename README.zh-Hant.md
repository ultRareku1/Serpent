# Serpent

[🇺🇸 English](README.md) · [🇨🇳 简体中文](README.zh-Hans.md) · [🇹🇼 繁體中文](README.zh-Hant.md) · [🇯🇵 日本語](README.ja.md) · [🇰🇷 한국어](README.ko.md) · [🇫🇷 Français](README.fr.md) · [🇩🇪 Deutsch](README.de.md) · [🇪🇸 Español](README.es.md)

為 Apple Silicon Mac 打造的原生極簡貪吃蛇遊戲，使用 SwiftUI、AppKit 與 AVFoundation 開發。執行時不依賴第三方套件，也不會發出網路請求。

## 操作方式

| 動作 | 操作 |
| --- | --- |
| 移動 | 方向鍵、WASD，或在遊戲區域拖曳／滑動 |
| 開始、暫停或繼續 | 空白鍵 |
| 新遊戲 | R 或 ⌘N |
| 暫停或關閉設定／玩法說明 | Esc |
| 設定 | ⌘, |

吃掉食物，讓小蛇變長。預設情況下，撞到牆壁會結束本局；開啟「穿越邊界」後可以從對側出現。撞到自己的身體始終會結束本局。直接轉向 180° 的操作會被忽略；快速輸入的有效轉向會依序排入佇列，在接下來的移動步驟中逐一執行。

切換至其他應用程式、最小化視窗，或讓 Mac 進入睡眠時，遊戲會自動暫停。回來後按空白鍵即可繼續。

## 功能特色

- 原生桌面視窗，可調整大小，支援全螢幕與 Retina／高 DPI 顯示。
- 提供淺色、深色與跟隨系統的外觀選項，預設跟隨 Mac 的外觀。
- 以 60 Hz 流暢繪製畫面，食物會柔和地明滅，分數更新也帶有動畫。
- 三種難度各自記錄最高分：

  | 難度 | 每次移動間隔 | 每份食物得分 |
  | --- | --- | --- |
  | 簡單 | 160 ms | 10 |
  | 普通 | 105 ms | 20 |
  | 困難 | 70 ms | 30 |

  難度變更會在下一局生效。

- 在「設定 → 遊戲設定」中提供獨立的「穿越邊界」開關，預設關閉。開啟後，小蛇越過一側邊界時會從對側出現；開關變更在下一局生效，撞到自己的身體仍會結束本局。每種難度的一般模式與穿越模式分別記錄最高分，原有一般模式紀錄保留。

- 可選擇開啟輕柔的合成音效，在開始、吃到食物、暫停、本局結束與刷新最高分時播放。
- 最高分、偏好設定與語言選擇會儲存在本機。
- 完整支援八種語言，可在「設定」中透過旗幟選擇：

  | 語言 | 地區 |
  | --- | --- |
  | 🇺🇸 英文 | 美國 |
  | 🇨🇳 簡體中文 | 中國 |
  | 🇹🇼 繁體中文 | 台灣 |
  | 🇯🇵 日文 | 日本 |
  | 🇰🇷 韓文 | 南韓 |
  | 🇫🇷 法文 | 法國 |
  | 🇩🇪 德文 | 德國 |
  | 🇪🇸 西班牙文 | 西班牙 |

  預設語言會跟隨 Mac 的偏好語言。你可以隨時在「設定」中變更。

## 開發與封裝

需要 Xcode Command Line Tools 與 Swift 5.9 或更新版本。

```sh
swift test
swift run Serpent
./Scripts/build-app.sh
```

封裝腳本會建立 arm64 應用程式與 ZIP 壓縮檔，接著驗證應用程式簽署。執行 `BUILD_DMG=1 ./Scripts/build-app.sh` 還可產生磁碟映像檔。

本機建置的版本採用 ad hoc 簽署，尚未透過 Apple Developer ID 完成公證。如果在另一台 Mac 下載後遭到 macOS 阻擋，請依照系統提示允許開啟。

自動化測試涵蓋遊戲規則、轉向佇列、邊界情況、自動暫停、系統語言比對，以及八種語言的翻譯完整性。

原始碼位於 `Sources/Serpent`，翻譯位於 `Sources/Serpent/Resources`，應用程式圖示與中繼資料位於 `Support`。
